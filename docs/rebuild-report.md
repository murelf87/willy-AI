## Encargo

- Objetivo: quiero tener la app para usar en el movil, funcional 100% y que pueda usarla con todos los videos y ejercicios que trae dentro, haz lo necesario porfavor
- Nivel: Producto completo
- Entregas: Código fuente, Aplicación compilada, Instalador, Documentación, Informe de pruebas
- Destino Windows: posible — Se compila, se instala y se prueba en este mismo equipo.
- Destino Web: posible — Se prueba en tu navegador; para publicarla hará falta un alojamiento (lo dice el plan técnico).
- Destino iOS: BLOQUEADO — Apple solo permite compilar, firmar y probar apps de iPhone en un Mac con Xcode y una cuenta de desarrollador de Apple: desde un equipo con Windows no se puede entregar verificada.
- Destino Android: con requisitos — Hace falta el SDK de Android (Android Studio) en tu equipo y un móvil Android o un emulador para probarla de verdad.
