# Welcome to your Lovable project

## Instalar WILLY AI en Windows 11

1. Pulsa **Code → Download ZIP** en GitHub.
2. Extrae el ZIP descargado.
3. Abre la carpeta **INSTALADOR_WILLY_AI**.
4. Haz doble clic en **INSTALAR_WILLY_AI.bat**.

El archivo prepara y comprueba automáticamente el instalador WILLY AI 0.0.7 antes de abrirlo. Las piezas están separadas para que GitHub pueda guardarlas sin superar su límite por archivo.
